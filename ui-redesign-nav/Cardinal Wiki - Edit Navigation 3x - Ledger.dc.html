The five modes are really two questions, so the dialog asks them as two: what the page shows, then how far that reaches. Inherit has no reach, so step 02 drops out when it is picked. Selection is the block picker's: an accent hairline with four marks, no fill. A centred dialog with the dark eyebrow, because this changes what every page below sees and deserves the heavier object. Edit menu items becomes a flat link in the footer, next to the actions it leads on from.

No floating layer. The footer button flips the sidebar column itself into the form, at exactly the width the result will occupy, and the page stays readable beside it. Rows are the tree's own rows: the chosen one lifts to white with the 2px accent edge, the same mark the active page wears, and the hint appears only there. The Menu source header is the settings-row primitive. The footer that opened this becomes Cancel and Save, split down the middle; there is nothing to dismiss and nothing to drag out of the way.
