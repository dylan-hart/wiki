**Add**, under `sslOptions`. This is operator documentation in the sample config rather than a code
comment, so it's listed here for a human to decide on, not applied.

Proposed:

```yaml
# Optional: a direct route to Postgres for the connections that need a real
# session (the LISTEN/NOTIFY clients), for when host/port above point at a
# pooler such as PgBouncer. Only host and port differ. Ignored while
# DATABASE_URL is set: use DATABASE_DIRECT_URL (a full connection string,

#   host: postgres.internal
```

Reason: the sample is where operators discover config keys. Without it, `db.direct` shows up only
in `base.yml` (as nulls) and in the deployment doc.
