# Cardinal wiki — project notes

## Source

Built from the `scarlett` branch of `dylan-hart/wiki` (Wiki.js 3.x: Vue 3 + Vite + Tailwind, in-repo `W*` component library). See `github.md` for the screen map. The 2.x-based files (page-view options board, old Ledger, Admin, Editor) are reference only — do not extend them.

## Design decisions to keep

- **Ledger** is the locked visual language: continuous light slate chrome, hairline borders, blueprint corner marks, Barlow Condensed over Barlow, Roboto Mono for metadata, one pastel cardinal red accent (#e4676b fills / #c14a52 for accent TEXT on white/paper, #a83f45 for links and accent text on the tinted #eef1f7 / #f0f2f7 strips) reserved for the live edge — active nav, primary action, alerts.
- **Light text tiers**: body #2f3a4f, secondary #4e5d7d, caption/faint #57668a. Nothing lighter than #57668a carries text on paper — #8a99b8 and #64789f are for hairlines, icon strokes and separators only. Positive text is #3f7a66, not the #5f9c86 fill.
- **Dark theme**: ink #14171f, panel #1b1f2a, raised #242b3a, hairline #2a3040, text #e6eaf2 / secondary #9aa6bd / faint #8792ab, slate-light #8ea6cf. The accent lightens to #f08287 and takes DARK ink on fills (white on it is under contrast); filled toasts darken (#3f7a66 / #a83f45) rather than lighten. See the dark primitives sheet.
- **Overlay sizing**: the inbox and profile overlays sit at 50% of the viewport, centred, content scrolling inside. The file manager and page history overlays stay near-full-bleed (24px scrim margin).
- **Public site (`Cardinal Site - *.dc.html`)**: cardinal.wiki marketing pages in the Ledger language. Primary buttons fill `#c14a52` with white (the repo's contrast divergence), selected segments fill `#e4676b` with ink. Status honesty is a rule: anything not in the repo yet carries a `Planned` badge and a dashed "proposed command shape" block, never a runnable-looking command. Import commands are the real `npm run migrate` / `verify-migration` flags from `backend/migration/source-args.ts` + `cli.ts`. Container image tag `ghcr.io/cardinal-wiki/cardinal:3` is a placeholder until a registry exists.
- **Edit navigation**: the popover (option 1a, locked) off the sidebar's Edit navigation footer — never a dialog. 344px, header eyebrow + mono path, cascade-mode rows with the parent/page/descendants glyph (affected rows filled accent, hidden rows dashed), Menu source segmented, outlined "Edit menu items…" hand-off, slate Save. Ledger: two opposite corner marks, 28px plates, tinted #f0f2f7 row with 2px inset accent. Cobalt: 8px card, 30px shadowed plates, #e6edff row with 3px #ff4d5a inset, round radios, 6px segments/buttons, #1e2a5e Save.
- **Back to top** (`ledger/Cardinal Wiki - Back To Top 3x - Ledger.dc.html`, turn 2 locked): third cell of the sidebar `.sidebar-actions` strip — locale | browse | top. Row 40px (Ledger + 1px hairline; Cobalt none). Locale is a fixed 72px cell (Cobalt 68px tile), Browse takes the remainder; the trailing 40×40 cell is always reserved so EN/Browse never shift; Top and (Ledger) its separator fade in together past 150px scroll. Ledger: white plate, 15px arrow + 7.5px mono TOP in #c14a52, hover #fdeced. Cobalt: all three actions are flat 6px-radius tiles with 4px gutters, hover rgba(255,255,255,.08); Top is a 32×32 tile, #ff8f97 glyph, hover rgba(255,77,90,.18). The repo's corner disc (WPageScroller) goes in wide mode; below 1200px the corner button stays.
- **Tabset block** (`Cardinal Wiki - Tabset Block 3x.dc.html`, handoff `handoff-5/tabset-block.md`): the `block-tabs` custom element drops its own card (shadow, gradient strip, Quasar blue) and takes `--tabs-*` custom properties from the theme. Ledger: square hairline frame with two corner marks, #f0f2f7 strip with 1px rules, active tab white with a 2px #e4676b top inset and #c14a52 type. Cobalt: 8px matte card, #e6edff strip with 4px gutters and no rules, tabs are 6px-top-radius tiles, active white with a 3px #ff4d5a cap and #1f4fd6 600 type. Dark variants follow the dark palettes above.
- **Other blocks** (`Cardinal Wiki - Block <Name> 3x.dc.html`, handoff `handoff-5/blocks.md`): Infobox, Spoiler, Checklist, Index, Countdown, Live Data, Gallery each get the tabset treatment — structure and behaviour untouched, `static styles` swapped for theme custom properties. Shared rule: Ledger blocks are square hairline plates with two corner marks, mono eyebrows for small labels, Barlow Condensed for numerals/headings, accent #e4676b only on the live edge (hover inset, sparkline, checked box); Cobalt blocks are 8px matte cards (6px inner tiles), no rules, tint fills for separation, cobalt for titles/numerals, red only for status. The `Block Figures` board covers the eighteen figure/embed/renderer blocks through the three shared fragments (caption, embed frame, error box).
- **Page actions rail**: duplicate, rename/move and delete are NOT separate rail buttons. Fold them into the more (`...`) menu alongside rerender and backlinks. The rail keeps: page properties (primary), pending assets (editing only), history, export, more.

- **Icons**: Tabler via the repo's bundle (`frontend/src/assets/icons.generated.js`, copied into the project): stroke-width 1.5, butt caps / miter joins (Tabler's round caps are stripped; only dot marks keep `stroke-linecap="round"`). Every icon in the screens carries `data-icon="tabler:<name>"` and its body is pasted verbatim from the bundle — never hand-draw a glyph. Colour goes on the `<svg color="…">` so `currentColor` resolves. Rail primary = `tag`, pending assets = `photo-cog`, history, `file-export`, `dots`; header: `plus`, `folder`, `hierarchy`, `inbox`, `tool`; search field trailing = `tags`; sidebar defaults `folder` / `file-text`; locale = `language`, browse = `sitemap`, edit nav = `list-tree`, back to top = `arrow-up`.

## Themes

Two themes ship. Filenames carry the theme suffix: `Cardinal Wiki - <Screen> 3x - Ledger.dc.html` (default, the brand) and `Cardinal Wiki - <Screen> 3x - Cobalt.dc.html` (the loud alternate).

- **Cobalt** is the alternate: solid cobalt top bar (#1f4fd6, white type and icons), deep-indigo sidebar (#10194a, active item cobalt with a 3px #ff4d5a inset bar), tinted ground #f2f5ff, white cards with 8px radius and a 1px #dfe5f5 hairline *border* instead of shadows and corner marks (the "matte" take, locked). **No drop shadows anywhere in Cobalt** — no card shadows, no red glow under Edit, no glow under the banner; only inset bars and 0-blur rings stay. **No hairline *rules* either** — no 1px edge rules between rows, panels, toolbars or sidebar bands, no 1px separator spans; separation inside a card comes from fill and gap. The border goes only on top-level plates that sit low-contrast on the ground (page content, contents, tags/revision, rail, admin cards); dark-ground elements (sidebar, top bar, overlays on the scrim) carry none. Banner is flat #1f4fd6 (no gradient). Accent red is #ff4d5a for untexted fills (dots, inset bars) and #c8303c for any fill carrying white text (Edit, badges, selected segments) and for accent text; links are cobalt #1f4fd6. Body #1a2038, secondary #4a5580, faint #5a6699. h2 in cobalt with no rule. Code blocks #10194a, 8px radius. Dialogs and overlays (inbox, profile, history, file manager, table editor, block picker, menus, confirm) take a 12px radius with `overflow:hidden`; the side dialog rounds only its outer edge (12px 0 0 12px). No dark eyebrow bar on dialog tops — the rounded corner is the edge. **Corner fringe fix**: a dark header clipped by a filled panel's `overflow:hidden` radius leaves a light antialias fringe at the two top corners (worse when the panel is also `overflow:auto`, which Chromium clips to the padding box). The panel is therefore `background:transparent` and does not scroll; the header carries `border-radius:12px 12px 0 0` (side dialog `12px 0 0 0`), and a body wrapper carries the surface fill, `border-radius:0 0 12px 12px` and the `overflow:auto`. In the repo: `.body--cobalt .main-overlay .w-dialog-panel { background: transparent }`, round the header slot on top and the body slot on the bottom with the surface fill and the scroll. Header eyebrow on cobalt is #dfe6ff, not #b9c8ff. Radii: cards/fields 8px, buttons/toasts/banners/callouts 6px, chips/tags/toggles pill, badges/checkboxes/code marks 3–4px — nothing square-cornered in Cobalt.
- **Cobalt dark** (`Cardinal Wiki - <Screen> Dark 3x - Cobalt.dc.html`; page view + primitives done, matching the Ledger dark set): ground #0a0f2c, sidebar #0e1540, card/raised #141c4f with a 1px rgba(255,255,255,.1) border, code block + footer #070b22, no shadows and no hairline rules (same rule as light Cobalt). Top bar deepens to #1a43bd (badge ring follows); banner gradient, active sidebar item and #c8303c white-text fills (Edit, Draft, avatar, rail) stay as in light. Text #e8ecff / secondary #a7b3ea / faint #8b98d6; breadcrumb separators #3a4680. Cobalt lightens for anything on dark ground: h2, links, rail icons and breadcrumb current #8fb0ff, body links #7fa0ff, numbered steps and callout rule #3d6df7, callout fill rgba(61,109,247,.16) with #c9d6ff text, cobalt tags rgba(61,109,247,.22) / #a3bbff. Accent text lightens to #ff8f97 on rgba(255,77,90,.16) fills (inline code, contents active, on-call tag); footer link #ff7a84.
- **Aesthetic setting**: `site.theme.aesthetic` (ledger|cobalt, default ledger) as the first row of the admin Theme › Appearance card; `user.aesthetic` (site|ledger|cobalt, default site) as a second segmented set beside light/dark in the profile Appearance row. Board: `Cardinal Wiki - Aesthetic Setting 3x.dc.html`. Handoff: `handoff-3/`.
- Canonical Cobalt page view: `cobalt/Cardinal Wiki - Page View 3x - Cobalt.dc.html` (locked from option 1a in `Cardinal Wiki - Theme Takes 3x.dc.html`, then the matte take from the since-deleted Page View Variations board). The other Cobalt screens were derived mechanically from the Ledger set and may need hand polish.
