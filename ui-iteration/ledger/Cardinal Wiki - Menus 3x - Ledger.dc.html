Menus & pickers
Four surfaces that had no Ledger treatment yet: the create menu, the same menu as the sidebar's right-click, the Browse panel's up button, and the tree-browser dialog that names a new page. Menu rows carry the 34px hairline plate the settings rows already use, so a menu and a settings list read as the same material.
01  Create menu
Opened by the header's New page button, anchored bottom-right to top-right so its edge lines up under the button. One row per editor the site has enabled, then the two imports, then assets behind a rule.

A row is present only if the site has that editor enabled; nothing sits here disabled. The Markdown row is the hovered state — a full-strength label, a plate that keeps its hairline, and the accent taken by the glyph rather than the row.
Redirection is always offered: it authors nothing, so no editor toggle governs it. The asset rule only appears where uploading is permitted.
Corner marks on two opposite corners only. A menu is a light object — the full four belong to dialogs and cards.
02  Sidebar context menu
The same menu, opened by right-click on a nav row and placed at the pointer. It gains a New folder rule, and the row it came from stays marked while it is open so the target is never in doubt. Only rows generated from the tree carry it — a hand-authored link has no path to create against.

Rules
Right-clicking a folder creates inside it; right-clicking a page creates beside it, in the folder it lives in. The mono line at the top of the panel says which of the two happened, so the menu is never ambiguous about where the page will land.
Plates drop to 28px here and the imports thin out to one row — a pointer-anchored menu should not be taller than the tree it covers.
The target row keeps the accent edge it wears while open. On touch, a long press opens the same panel at the finger.

The tree column is tinted so it reads as its own column rather than running into the list beside it; both scroll independently inside the same fixed 300px, so a deep folder never pushes the fields off the dialog. Selection is the one accent fill on the sheet — the folder being saved into, and nothing else.
Typing a title slugs the path below it until the path is edited by hand, after which the two are independent. A slash in the path name is refused inline and disables Save rather than failing after the click. Clicking a page in the list adopts its title and slug, which is how the dialog offers overwriting.
