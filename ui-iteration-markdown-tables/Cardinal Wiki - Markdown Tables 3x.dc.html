Turn 1  rendered markdown tables
Tables in the article column, both aesthetics
GFM pipe tables render to a plain <table> inside the page content. Column alignment (:---, :---:, ---:) is honoured; right-aligned columns are treated as numeric and set in Roboto Mono with tabular figures. Both aesthetics keep row rules and banding for readability; they differ in how those are drawn. The table sits in a scroll wrapper so wide tables scroll inside their frame instead of breaking the column. Each frame below is the table in the article, light and dark, then the hover row and a 300px wide-table case.
1a
Ledger
A ruled ledger sheet: hairline frame with two corner marks, mono eyebrow header on the tinted strip, row and column rules, faint banding.

Health gates

Each batch is held against four gates. A breach on any of the first two aborts the rollout and leaves the batch drained.

Gate Threshold Window Action on breach
p99_latency < 250 ms 60 s Abort batch
error_rate < 0.5 % 120 s Abort batch
queue_depth < 50 000 5 min Pause, resume when the depth recovers. See Queue topology.
consumer_lag < 2 000 msgs 60 s Warn only

Thresholds are read from the release manifest, so a hotfix can loosen a gate without a config deploy.

Wide table, 300px — scrolls inside the frame
Spec. Frame 1px #dbe1ec, square, no shadow, two opposite corner marks (7px, #64789f), 20px vertical margin; the marks sit on the frame, the scroll wrapper is inside it. Header strip #f0f2f7, Roboto Mono 600 10.5px, .14em tracking, uppercase, #4e5d7d, 1px #dbe1ec rules below and between columns. Body cells 9px 14px, Barlow 14.5px/1.5 #2f3a4f, top-aligned, 1px #dbe1ec row rules, 1px #e9edf3 column rules; the last row and last column drop their rule so the frame closes the grid. Every second body row is banded #f7f8fb (the strip colour, one step lighter) so the eye can track a row across wide tables. Right-aligned columns switch to Roboto Mono 13.5px with tabular figures and no wrap. Inline code, links and bold inherit the article's styles. Hover: row #eef1f7 (over the band), 2px #e4676b inset on the first cell. Dark: frame, header and row rules #2a3040, column rules #232838, header #14171f, body #1b1f2a, text #e6eaf2, header text #9aa6bd, accent #f08287, band rgba(255,255,255,.025), hover rgba(255,255,255,.05). Wide tables keep their columns and scroll horizontally inside the frame (thin scrollbar, #c9d2e2 on #f0f2f7).
